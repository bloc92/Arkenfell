# Voyage item image reference archive

This directory preserves the 111 item images supplied as reference material for the Arkenfell item-image work.

- The PNG files are saved byte-for-byte from the supplied Voyage CDN URLs.
- Filenames are normalized from the item names for easier reuse.
- MANIFEST.tsv records the original item name, source URL, byte size, and SHA-256 digest.
- These are reference/source assets; they are not automatically assigned to Arkenfell item types.

Source set archived on 2026-09-19.
