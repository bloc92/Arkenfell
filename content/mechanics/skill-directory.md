# Skills of Arkenfell

Browse all **139 configured skills** in Arkenfell. Search by skill name, governing attribute, skill type, description, or starting equipment.

Select any skill name to open its individual article and review the full description and configured mechanical details.

Skills are grouped by their configured types: Combat, Magic, and Utility. For an explanation of how skills improve and how characters learn skills they did not start with, use the separate Skills and Learning New Skills guides.
