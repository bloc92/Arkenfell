# Skills

Skills represent learned competence. They are separate from attributes: an attribute provides broad aptitude while a skill represents training in a particular method or field.

## Skill Progression

- Maximum skill level: **100**
- Maximum skill success contribution: **100**
- Starting XP required for a skill level: **100**
- Additional XP required per skill level: **40**
- XP gained from learning a new skill: **200**
- Character XP per skill level: **20**
- Base XP from a skill upgrade: **125**
- Training cooldown: **10**
- Base chance to learn a new skill: **5%**
- Skill-learning bonus modifier: **0.5% per applicable point**
- New freeform skill generation is currently **disabled** in the configured world.

Configured skill XP rewards are **40 / 60 / 100 / 150** for small, medium, large, and huge rewards.

## Competence Benchmarks

Arkenfell commonly reads skill values approximately as:

- **20+ — Trained**
- **50+ — Experienced**
- **80+ — Expert**
- **100 — Master**

These are interpretation anchors rather than replacements for difficulty, opposition, equipment, injury, terrain, resources, or circumstance.

## Skill Domains

### Accuracy-linked work
Ranged, aimed, and thrown actions. Weapon skills and precise ranged techniques use Accuracy when the method is fundamentally about aim.

### Communication-linked work
Persuasion, deception, etiquette, bargaining, leadership, performance, verbal intimidation, rumors, and social inquiry. Common named skills include **Bargaining**, **Leadership**, **Social Inquiry**, and related social specialties.

### Constitution-linked work
Endurance, exposure, poison, disease, pain, and sustained bodily hardship. **Tolerance** is a common example.

### Dexterity-linked work
Stealth, acrobatics, locks, traps, legerdemain, riding, sailing, balance, and bodily precision. Named examples include **Acrobatics**, **Swimming**, **Traps**, and other movement or handling specialties.

### Fighting-linked work
Melee, brawling, dueling, parries, guards, shield pressure, and trained close-combat styles. Configured progression includes disciplines such as **Archery**, **Brawling**, **Dueling**, **Light Blades**, **Staff Fighting**, **Slings**, and **Shields**, with Discipline → Expertise → Mastery → Apex advancement traits where applicable.

### Intelligence-linked work
Lore, research, appraisal, medicine, engineering, cartography, navigation, records, relic study, and structured magical theory. Named examples include **Arcane Lore**, **Archival Research**, **Cultural Lore**, **Heraldry**, **Military Lore**, and **Natural Lore**.

### Perception-linked work
Senses, tracking, searching, clues, danger, and tells. Named examples include **Searching** and **Tracking**.

### Strength-linked work
Lifting, climbing, jumping, grappling, forcing, carrying, mining, smithing, and breaking. **Jumping** and relevant craft/labor skills can rely on Strength when raw force is the method.

### Willpower-linked work
Courage, discipline, fear and pain resistance, compulsion resistance, magical pressure, concentration, and most direct Arcana. **Self-Discipline** is a recurring non-Arcana example.

## Arcana Skills

Skills whose names end in **Arcana** represent actual magical practice in that affinity. They count as Arcana skills for use and progression. **Arcane Lore** does not: it is knowledge about magic rather than an affinity itself.
