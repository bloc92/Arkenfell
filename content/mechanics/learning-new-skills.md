# Learning New Skills

Characters are not limited forever to the skills selected during character creation. Arkenfell contains a broad configured skill list covering combat, movement, social activity, scholarship, professions, perception, survival, and magical practice.

A character can learn a configured skill they do not yet possess when play establishes a believable opportunity to acquire it.

## How to Learn a Skill

The clearest route is to make the character's intent part of the story:

1. **Find a relevant opportunity.** Seek a teacher, school, guild, manual, training ground, working professional, or practical situation.
2. **State what the character is trying to learn.** Asking an NPC for instruction is more useful than performing unrelated actions and hoping a skill appears.
3. **Practice the actual discipline.** The character should train or attempt actions that genuinely use the skill.
4. **Continue through setbacks.** A single lesson or attempt is not guaranteed to unlock a new competence.
5. **Let the learning check resolve.** When the conditions are appropriate, the game can add the skill to the character.

A capable teacher, strong related aptitude, sustained practice, and a meaningful training situation all make the process more credible. Learning attempts are paced so repeating the same command every turn is not an effective shortcut.

## Only Established Skills Can Be Learned Automatically

The game can automatically unlock skills that already exist in Arkenfell's configured skill list. It will not invent a completely new permanent skill category during play.

If an intended discipline is not configured, the closest existing skill should be used. New permanent skill categories must be added to the world itself.

## Other Ways Skills Can Be Granted

Some traits, story rewards, transformations, or scripted events can grant a skill directly when their rules say they do. These are specific rewards rather than the ordinary training process.

A trait that provides a bonus to a missing skill can also establish that skill for the character.

## Skills and Abilities Are Different

A **skill** is broad learned competence, such as Bows, Persuasion, Smithing, or Fire Arcana.

An **ability** is a particular technique or named action. Abilities can require a minimum skill level, character level, attribute, resource, or trait. As a skill rises, abilities tied to its higher thresholds can become available to unlock.

Learning a skill therefore opens a path of development; it does not immediately grant every ability associated with it.

## Practical Examples

- A character who wants **Smithing** might apprentice under a forge worker and take part in real repair or crafting work.
- A character who wants **Persuasion** might study under a negotiator and repeatedly handle meaningful social situations.
- A character who wants **Bows** might train with an archer, practice safely, and use a bow under genuine pressure.
- A character who wants an **Arcana skill** must first have a credible route to that magical affinity; access and mastery are separate.
