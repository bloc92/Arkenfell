# Milestone Titles

Characters earn formal milestone titles at specific levels. These titles mark major thresholds in progression and use the following canonical names and levels.

| Level | Title |
| ---: | --- |
| 5 | Firstmark |
| 10 | Starbearer |
| 20 | Boundbreaker |
| 30 | Ascendant |
| 40 | Saint |
| 50 | Calamity |
| 60 | Dreadstar |
| 70 | Mythwalker |
| 80 | Starbane |
| 90 | Heavensbane |
| 100 | Apotheon |
